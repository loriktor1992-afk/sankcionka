# Инструкция по использованию парсера idubid.com

## Подготовка к работе

1. Убедитесь, что у вас установлены все зависимости:
   ```
   pip install selenium beautifulsoup4 requests
   ```

2. Установите Chrome WebDriver, соответствующий вашей версии Chrome

## Запуск парсера

1. Запустите скрипт:
   ```
   python parser_idubid.py
   ```

2. Введите желаемый бренд для парсинга (например: toyota, nissan, honda и т.д.)

3. После запуска браузера:
   - Вручную войдите в свой аккаунт на idubid.com
   - Перейдите на страницу со списком автомобилей (обычно через поиск или каталог)
   - Нажмите Enter в консоли после перехода на нужную страницу

4. Парсер начнет автоматическую обработку автомобилей

## Особенности работы

- Парсер проверяет STOCK ID перед открытием карточки автомобиля
- Если автомобиль с таким ID уже был обработан, карточка пропускается
- Все найденные автомобили будут отнесены к выбранному бренду
- Программа сохраняет прогресс и может быть возобновлена после остановки

## Обработка ошибок

- При возникновении капчи процесс приостанавливается - решите капчу вручную и нажмите Enter
- Программа автоматически повторит попытку при ошибках
- Прогресс сохраняется в файл parser_progress.json

## Ограничения

- Максимальное количество автомобилей для парсинга: 1500 (настраивается в MAX_CARS)
- Максимальное количество фото на автомобиль: 20 (настраивается в MAX_PHOTOS_PER_CAR)
